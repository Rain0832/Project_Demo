# 🧠 **最白话解释**

## **1. 数组是“固定长度”；切片是“可伸缩的视图”**

用生活类比：

* **数组 array = 固定容量的蛋托，买来就不能变大小**
* **切片 slice = 在蛋托上盖一张“透明膜”，膜的大小可以随时加大**

你几乎不会直接操作数组，
Go 所有正常业务代码全用 **切片**。

---

## **2. 切片本质：指向底层数组的一个窗口**

切片其实是一个结构体：

```
指针   → 指向底层数组
长度   → 当前看到几个元素
容量   → 底层数组最多还能放几个
```

所以这段很关键：

> **切片传递给函数是“引用语义”——修改会影响原切片**

---

## **3. len 和 cap**

* len = 眼睛能看到的元素数
* cap = 底层数组还能容纳多少

比如：

```go
s := make([]int, 2, 5)
```

底层数组容量是 5，但你只看得到前 2 个。

---

## **4. append 自动扩容，但可能换底层数组**

当切片容量不够时，Go 会自动：

1. 分配一个更大的底层数组
2. 把原来元素复制过去
3. 返回一个新的切片

所以 append 后的切片可能不再共享底层数组。

---

## **5. 切片的三种创建方式（你必须掌握）**

### **① 字面量（最常用）**

```go
s := []int{1, 2, 3}
```

### **② make（控制容量）**

```go
s := make([]int, 0, 10)
```

### **③ 从数组/切片切出来**

```go
a := [5]int{1,2,3,4,5}
s := a[1:4]
```

# 📚 **本关会用到的语法/API**

* 切片声明：`[]T`
* make：`make([]T, len, cap)`
* append：`append(s, elem)`
* len()、cap()
